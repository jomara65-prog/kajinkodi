# Mobile App Plan

Suggested implementation: Flutter or React Native

## MVP Screens
- Auth and onboarding
- Dashboard (weather, tides, moon, wind)
- Map (sightings, trap status, safe zones)
- Catch/sighting log entry
- Quest mode and monthly leaderboard
- Alerts inbox (trap tamper, door state, battery)
- Co-op listings and guide booking

## Device Controls
- Read telemetry (motion, weight, door, battery)
- Queue commands (arm/disarm/reset) with policy checks
- Command confirmation and audit history
